> **Hackathon Submission**: Prompt Wars 2026  
> **Aesthetic Theme**: Premium Light Mode (Slate / Calm Teal-White)  
> **Key Innovation**: Voice-First Recovery Assistance, Localized Indian Emergency Protocols & Caregiver Support Workspaces

---

## 🌟 Executive Summary

**Beacon AI** is a premium, trust-focused, voice-first digital healthcare platform designed to provide grounding support and emergency guidance for individuals navigating Substance Use Disorders (SUD) and their caregivers in India. 

Designed for moments of crisis and emotional distress, Beacon AI replaces heavy dashboards and text inputs with a simplified, voice-first interaction model inspired by Calm, Headspace, and Apple Health:

- 🎨 **Calm Light-Theme Design**: Warm slate neutrals, white surfaces, subtle shadows, and generous whitespace. Cyberpunk neon elements, dark backgrounds, and technical labels are replaced with a calming, trust-first environment.
- ⚡ **Zero-Typing Grounding**: Rating crave intensity and logging triggers with a 1-tap visual scale.
- 🎙️ **Voice-First Assistance**: A large central microphone button designed to minimize cognitive load during panic or urge peaks. Users speak naturally and receive empathetic spoken voice responses.
- 👥 **Dual-Role Workspaces**: Tailored workspaces for individuals in recovery and loved ones offering caregiver assistance.
- 🇮🇳 **Indian Helpline Integration**: Direct workflows for **112** (National Emergency), **108** (Medical), **14446** (Tele-MANAS Mental Health), and **1800-11-0031** (De-Addiction Helpline).

## 🚀 Quick Start & Vercel Deployment

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AparnaK978/Promptwars_2026.git
   cd Promptwars_2026
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Launch Development Server**:
   ```bash
   npm run dev
   ```

4. **Deploy directly to Vercel**:
   ```bash
   npx vercel --prod
   ```

> **Beacon AI** is an assistive support tool designed to complement professional care and harm reduction strategies.
